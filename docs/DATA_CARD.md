# 数据与评测卡

来源：CMRC2018官方GitHub仓库，revision c0eb1b6ba219847457e6af3180da722bbeb656af，squad-style-data/cmrc2018_train.json，SHA256见configs/protocol.json。数据许可CC BY-SA4.0，完整归属见DATA_LICENSE.md。输入2,403文段、10,142问题；真实源全文不提交，提交必要语料与320题评测子集。

## 算子与质量标签

- 非空、字段类型、source_id冲突属于确定性契约；联系方式正则是**疑似标记**，不能认定真实PII，不能覆盖所有邮箱、电话、人名或身份证。当前真实语料命中0；合成fixture用于证明隔离行为，不证明生产识别精度。
- 对评测参考答案做非空与原文offset完全一致检查，21题未通过。它们不一定语义错误；当前只知道参考位置不满足协议。未使用模型结果决定排除，不修改gold或回填答案。
- 原始text保留；精确重复基于完整text内容hash。真实2,403文段精确重复0，不能报告不存在的清洗收益。
- 64bit SimHash（字符5gram）以4个16bit band生成候选，Hamming<=3后再要求Jaccard>=0.85；发现一对相似文段，Jaccard约0.936。它们保留为独立文档，但合并为评测家族。候选机制不是对所有高Jaccard对的完备搜索，更不等于语义去重。

## 划分与信息边界

共同归一化标题或检测到的近重复关系先组成连通家族，再按固定hash排序选320家族，每家族一题，160dev+160holdout。文段是检索语料，包含评测问题对应文段是任务设定；**问题、答案、参考offset和标题不进入BM25文本索引**。它们只用于抽样/评分，不能误称闭卷能力。

完整CMRC公开dev只用于旧集合排除：相同原文或归一化标题会排除。实际没有这些排除命中；没有对旧dev做穷尽语义近重复排除。因此只能称来源文件和显式重合排除，不能称所有语义无交集。既有英文test、跨文章64题与中文96题未进入本项目评分、改进选择。

## 指标与限制

原文档recall@3：top3至少一块来自标注doc_id。span-hit@3：还需块的原始[start,end)完整包含至少一个标注答案位置。偶然相同字符串出现在别的文档不计命中；答案太长无法落入160字符块仍计失败。oracle coverage遍历所有本方案块，区分“切块根本丢证据”与“证据存在但检索未找到”。

字符BM25使用NFC/casefold后的字母数字单字符与双字符，固定k1=1.2、b=0.75；查询词频参与分数，tie按chunk_id。没有神经模型、模型预训练污染问题的测试、生成回答或语义蕴含判断。480字符不是480token；不控制LLM上下文token成本。返回重叠字符重复占预算，因而可能挤占更多来源。

公开train在本项目重新划成dev/holdout，不是官方隐藏test，不代表企业知识库分布。样本只有可回答问题，不能验证信息不足时的拒答；这里没有拒答模型。看过本轮holdout后不可再据其调参并宣称独立验证。
