# 项目名称与兼容性

项目展示名称：**中文数据处理与检索**。

GitHub 仓库名：`ChineseTextProcessingAndRetrieval`。

历史仓库名：`chinese-evidence-data-engine`、`chinese-text-pipeline`。旧名仅用于历史溯源。

## 获取代码

```sh
git clone https://github.com/kimzclandi/ChineseTextProcessingAndRetrieval.git
cd ChineseTextProcessingAndRetrieval
```

已有 checkout 可在仓库根目录更新 remote；本地目录是否改名不影响运行。

```sh
git remote set-url origin https://github.com/kimzclandi/ChineseTextProcessingAndRetrieval.git
```
